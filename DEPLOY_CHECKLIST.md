# Y7–8 Assessment — quick deployment checklist

- [ ] Create standalone Apps Script project.
- [ ] Paste `Code.gs`.
- [ ] Add HTML file named `Index` and paste `Index.html`.
- [ ] Add supplied `appsscript.json`.
- [ ] Run `setupAssessment_()` once and authorise.
- [ ] Open the response spreadsheet URL from the Execution log.
- [ ] Deploy as Web app → Execute as Me.
- [ ] Choose an access setting pupils can use.
- [ ] Open deployed URL on a pupil PC.
- [ ] Confirm `Python runner: ready`.
- [ ] Test one fake submission.
- [ ] Refresh mid-test and verify Resume works.
- [ ] Verify exactly one Sheet row is created.
- [ ] Enter B1/B2/C1/C2 scores and check Total/Grade formulas.
- [ ] Keep marking file and Sheet private.
